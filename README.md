# Aplicación web de vehículos

Aplicación web desarrollada con Streamlit para realizar un análisis exploratorio de anuncios de vehículos.

La aplicación utiliza el conjunto de datos `vehicles_us.csv` y permite visualizar información sobre los vehículos mediante gráficos interactivos creados con Plotly Express.

## Funcionalidades

- Vista previa del conjunto de datos.
- Histograma de la distribución del kilometraje de los vehículos.
- Gráfico de dispersión para analizar la relación entre el precio y el kilometraje.
- Controles interactivos para mostrar las visualizaciones.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit

## Ejecución

Para ejecutar la aplicación localmente:

`streamlit run app.py`
